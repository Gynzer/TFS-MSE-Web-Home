STL MSE Web Resources

MSE Web Resources

There are several web based resources that the MSE use on a regular basis. Most of these require separate authentication and authorization. If you believe that you need access to one of these resources, please contact the MSE Automation Team.

Claroty SRA

Claroty Secure Report Access (SRA) allows our MSE team, and in some cases vendors, to have controlled access to our networked equipment located within the manufacturing space.

Access: Contact MSE Automation Team

Claroty CDT

Claroty Continuous Threat Detection (CDT) is used for monitoring and protecting our building OT devices for things like intrusion detection, viruses and malware.

Access: Contact MSE Automation Team

EEDMS

The Engineering Electronic Document Management System (EEDMS) is used by the engineering department to store and manage access forms, TOPs, Project Files and documents. It is powered by FileHold software.

Access: Contact the MSE Automation Team

Engineering Parts Management

The Engineering group is using a solution from MVPPlant to help us manage our parts. Our parts portal can be accessed through this link.

Access:AMER Domain UserID & PW

Marty's MSE Network Spreadsheet

Marty created a spreadsheet to rule them all. You should be able to find all of the MSE networking information that you need right here. For access, you must be part of the acess group in Teams/Sharepoint.

Access: Contact Marty

MSE SNOW Ticket Dashboard

This is a dashboard put together to show just the tickets associated with the St. Louis MFG site.

Access: Need to be in the proper SNOW Access Group

Reverse Proxy Stats

This link provides read only status of our web proxy and its connected servers.

Access: Read only access to the public.

vSphere Web Client

Our manufacturing server infrastructure is running under a VMWare host. This link allows our team to remotely manage our server instances.

Access: Need to be in the USSLO Server Automation Domain Group
