STL MSE File Resources

MSE File Resources

There are several web based resources that the MSE use on a regular basis. Most of these require separate authentication and authorization. If you believe that you need access to one of these resources, please contact the MSE Automation Team.

Due to security concerns, you will not be able to click on links to forward yourself to these resources. Instead, please copy and past the appropriate link either into your broswer or File Explorer. Also included is a command line for connecting to a resource with a different userid and password than your own.

MSE Equipment Software
