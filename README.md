# The MSE Web Home

## Source

This Git Project holds the code for the MSE Web Home page.    
It is built on top of the Foundation CSS Frameork (http://get.foundation).   
The Foundation code can be found in the directories ./assets/css
and ./assets/js.  For css over-rides for this web site, you can find
those placed in the ./assets/css/mse.css file.  To see the original
example home page, it has been saved as ./index-original.html .

Images supporting the web can be found in the ./assets/images directory.

Within this GitHub project, the entire contents of the web stie can be 
found under the /html directory.   The html directory contents can be 
considered the home or root of the publically available web site.  It is 
designed to be self referencing so that it can be placed in any web 
subdirectory.

I have been using Notepad++ to edit the files within the project and 
then have used a software package called 'FTP Voyager' to sync the files 
up to the web site located on the LInux based web server.   Since the 
web directory is locked, I use the method of creating a link from my 
accounts home directory to the web site directory.   That way I am 
essentially uploading my files to my local user space but it is mapped 
to the web site.  I use my AMER delegate account to access the web 
server.
